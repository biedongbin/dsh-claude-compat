## 实际展示的过程

0. 从主窗口点击侧栏插件，再点击Claude Code标签；完整管理页面实际停留约3秒，保留DSH标识、侧栏、主标题及管理导航。
1. `/cc-plugin`：在对话输入框逐字输入、点击发送、管理卡片原生展开、输入context7筛选、显示真实条目和管理按钮。没有执行安装/卸载等写操作。
2. `/cc-resume`：在对话中展开历史卡片、选择明确标注的合成历史、点击预览、点击阅读并总结。DSH实际读取该文件并输出背景、状态和下一步。
3. 英文版在接续之后实际追加英文总结请求，展示实际英文回答；并非替换或翻译页面里的模型回复。
4. `/demo-brief`：从真正的技能菜单选择临时Claude格式技能，提交请求，模型实际输出三条中/英文发布摘要。此技能仅演示配置桥接，不是产品内置能力。

## 本次节奏与几何诊断

对上一版所用4301张JPEG检查，全部1440×900；两份输出也是1440×900、SAR1:1。抽取英文短切前后的编码帧与对应源帧做同坐标比较，平均像素误差约0.6–0.8/255，未发现该处的几何拉伸。已确认的问题是0.95秒插入后约120像素的滚动/状态跳变、操作加速和结果未稳定就切走；因此修剪时间线和重录稳定结果，没有加入光流插帧或非等比缩放。

本次未重跑模型或重新安装插件；复用已生成的真实回答，实际导航到对应会话拍摄稳定结果。中文、展开侧栏和原视口尺寸已恢复。
