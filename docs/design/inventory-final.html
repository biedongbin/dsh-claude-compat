# 可点击本地文件链接（全局）

1. 凡是提到本机文件、目录、日志、截图、构建产物、附件等，一律输出为可点击链接。
2. 链接目标必须来自本次会话真实获取到的绝对路径；不得猜测、不得编造。
3. 使用本会话成功读取、创建或修改得到的实际路径。路径不确定、文件被移动或用户反馈失效时，先核实
   存在性及可读性；不得编造目标。
4. 不得只输出文件名、行内代码路径或代码块路径代替可点击链接。不要把整条 Markdown 链接包进反引号
   或代码块。
5. 保留完整文件名和扩展名，正确处理空格、括号、中文及其他特殊字符，避免链接截断或指向不同文件。

```js
// 代码块保持原样，不参与翻译
const answer = 42;
```

## HTTP/HTTPS 资源

1. 使用带 `http://` 或 `https://` 的完整、真实地址，并呈现为可点击链接。
